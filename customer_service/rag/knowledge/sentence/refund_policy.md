# 售后政策

> RAG 语料（P1）：替换 tools/aftersale_tools.py 里写死的 REFUND_POLICY。
> 内容先与 Mock 保持一致，方便做替换前后的对照验证。
>
> 语料设计说明（给未来的自己）：
> · 政策类语料最重要的不是"字数多"，而是**条款与它的适用条件必须挨在一起**，
>   否则切块后会出现"7 天"和"定制商品除外"被切到两个 chunk 的惨案，
>   AI 就会答出"定制商品也能 7 天无理由"这种致命错误
> · 每个条款后的「常见问法」是给检索用的锚点，
>   让口语化提问（"我买错了能退吗"）也能命中对应条款

## 总则

1. 本政策适用于本店全部自营商品，自订单签收之日起计算时效。
2. 时效计算以快递系统显示的签收时间为准；代收、快递柜签收均视为已签收。
3. 本政策与商品详情页特殊说明冲突时，以详情页特殊说明为准。
4. 政策外的特殊情形，由客服根据实际情况酌情处理。

## 退货

1. 签收后 7 天内支持无理由退货，商品需保持完好（配件、包装齐全）。
2. 定制类商品不支持无理由退货。
3. 退货运费：质量问题由商家承担，无理由退货由买家承担。
4. "商品完好"指不影响二次销售：外观无划痕、配件与包装齐全、无使用痕迹。
5. 以下商品拆封后不支持无理由退货：贴身用品（如耳机耳塞）、已激活的软件类商品、已撕毁防伪标的产品。
6. 无理由退货需在申请后 7 天内寄回，超时未寄回的申请将自动关闭。
- 常见问法：我买错了能退吗 / 不想要了怎么退 / 七天无理由是怎么算的 / 拆开了还能退吗

## 换货

1. 签收后 15 天内出现质量问题可免费换货，往返运费由商家承担。
2. 换货商品发出前会先检测原商品故障情况。
3. 无理由换货视同退货后重新下单，需按退货流程处理。
4. 换货仅限同型号同颜色；如需更换型号或颜色，请走退货退款后重新下单。
5. 换货周期：我们收到原商品并检测通过后 48 小时内寄出，物流时效另计。
- 常见问法：坏了想换个新的 / 质量问题换货要钱吗 / 能换个颜色吗 / 换货要等多久

## 退款

1. 退款原路返回，审核通过后 1-3 个工作日到账。
2. 未付款订单无需退款，可直接取消。
3. 已发货订单申请退款，需先拦截物流或签收后走退货流程。
4. 退款金额以实付金额为准，优惠券部分不退现金，按原券规则返还。
5. 使用余额支付的订单，退款优先退回余额，其余部分原路返回。
6. 退款进度可在"我的订单-退款详情"查看，显示"退款成功"即已发起，到账时间取决于支付渠道。
- 常见问法：钱什么时候退给我 / 退款退到哪里 / 优惠券会退吗 / 用了余额怎么退

## 运费与破损

1. 质量问题产生的往返运费由商家承担。
2. 无理由退货的退回运费由买家承担。
3. 商品在运输中破损的，买家提供照片（含快递面单）后，可选择免费补发或全额退款，破损件无需寄回。
4. 少发、错发商品经核实后免费补发，补发运费由商家承担。
- 常见问法：退货运费谁出 / 收到是坏的怎么办 / 少发了一件 / 发错货了

## 保修与维修

1. 数码类商品享受厂家全国联保 1 年，自签收之日起算。
2. 家具类商品提供 3 年结构件质保（框架、气压杆、扶手连接件）。
3. 保修期内非人为损坏免费维修；人为损坏或超保的按厂家标准收取配件与工时费。
4. 申请保修需提供订单号或购买凭证；走厂家联保的需提供发票。
5. 维修周期一般为收到商品后 7-15 个工作日，具体以厂家检测结果为准。
- 常见问法：保修多久 / 坏了免费修吗 / 人为弄坏的修要多少钱 / 保修要发票吗

## 发票

1. 支持开具电子普通发票，下单时在备注栏填写抬头与税号。
2. 发票于发货后 24 小时内发送至下单手机号对应的微信或短信。
3. 订单完成后 90 天内可联系客服重开或修改抬头。
4. 目前不支持增值税专用发票。
- 常见问法：怎么开发票 / 发票什么时候到 / 抬头写错了能改吗 / 能开专票吗

## 会员权益

1. 历史累计消费满 2000 元自动升级 VIP，无需申请。
2. VIP 享全场 95 折与售后优先处理通道。
3. 会员折扣与优惠券不叠加，结算时系统自动选择对用户更划算的一种。
4. 会员等级不因退货而降级，但退货金额会从累计消费中扣减。
- 常见问法：怎么成为 VIP / VIP 有什么用 / 折扣和券能一起用吗 / 退货会掉等级吗

## 投诉与升级

1. 对处理结果不满意可要求升级人工专员，专员将在 24 小时内回电。
2. 重大投诉将生成工单，由客服主管跟进，48 小时内给出处理方案。
3. 在线人工客服工作时间为每日 9:00-21:00，非工作时间可留言，次日 10:00 前响应。
4. 投诉处理结果不满意的，可申请二次复核，复核由质检组独立进行。
- 常见问法：我要投诉 / 对结果不满意 / 人工几点上班 / 投诉多久给回复

## 特殊商品说明

1. 定制类商品（刻字、改色、定制尺寸）：不支持无理由退货，质量问题可换货或维修。
2. 贴身用品（耳机耳塞、颈枕）：拆封后不支持无理由退货，未拆封可退。
3. 软件与虚拟商品：激活后不支持退货。
4. 大件家具（工学椅、升降支架）：退货需保持原包装，退回运费按实际物流费用结算。
- 常见问法：刻字的能退吗 / 耳机拆了能退吗 / 椅子退货运费多少 / 虚拟商品能退吗

## 隐私与数据

1. 收货信息仅用于订单履约与售后联系，不对外提供。
2. 客服通话与在线会话可能被记录用于质量检查，记录保留 6 个月。
3. 用户可随时要求删除账号与历史订单中的个人信息，法律法规要求保留的除外。
- 常见问法：你们会泄露我信息吗 / 聊天记录会被保存吗 / 怎么注销账号
